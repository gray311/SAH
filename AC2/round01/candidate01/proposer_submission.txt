      Analyze the current function's convolution properties to guide mutations.\nReturns: peak_value, peak_location, l1_norm, l2_norm_squared, norm_inf, variance, skewness.\nCall once at start of each iteration to understand what the optimizer found.\nThis helps decide whether to refine resolution, change optimizer, or try analytical improvements.

    implementation_py: |
      def run(ctx, args):
          import jax.numpy as jnp
          import jax
          
          f_values = ctx.get_program()
          
          # Ensure non-negative and discretize properly
          f_non_neg = jnp.maximum(jnp.array(f_values), 0)
          f_float = jnp.array(f_non_neg, dtype=jnp.float64)
          
          N = len(f_float)
          padded_f = jnp.pad(f_float, (0, N))
          fft_f = jnp.fft.fft(padded_f)
          convolution = jnp.fft.ifft(fft_f * fft_f).real
          
          # Normalize by grid spacing
          h = 1.0 / (N + 1)
          
          # L1 norm (integral approximation)
          norm_1 = jnp.sum(jnp.abs(convolution)) * h
          
          # L2 norm squared (integral approximation using Simpson's rule)
          y_points = jnp.concatenate([jnp.array([0.0]), convolution, jnp.array([0.0])])
          y1, y2 = y_points[:-1], y_points[1:]
          l2_norm_sq = jnp.sum((h / 3) * (y1**2 + y1 * y2 + y2**2))
          
          # Infinity norm
          norm_inf = jnp.max(jnp.abs(convolution)) * h
          
          # Variance and skewness
          mean_conv = jnp.mean(convolution)
          var_conv = jnp.mean((convolution - mean_conv) ** 2)
          std_conv = jnp.sqrt(var_conv + 1e-12)
          if std_conv > 1e-10:
              skewness = jnp.mean(((convolution - mean_conv) / std_conv) ** 3)
          else:
              skewness = 0.0
          
          return {
              "peak_value": float(jnp.max(jnp.abs(convolution)) * h),
              "peak_location": float(jnp.argmax(jnp.abs(convolution))),
              "l1_norm": float(norm_1),
              "l2_norm_sq": float(l2_norm_sq),
              "norm_inf": float(norm_inf),
              "c2_ratio": float(l2_norm_sq / (norm_1 * norm_inf)),
              "variance": float(var_conv),
              "skewness": float(skewness)
          }

      ## Overview
      When the evaluator is slow (minutes per call) and you have a cheap probe (~10s), use probes to screen many variants before committing to full evaluations.
  
      ## Workflow
      1. **Analyze**: Call analyze_convolution_stats to understand current solution

      6. **Iterate**: Repeat with best result
