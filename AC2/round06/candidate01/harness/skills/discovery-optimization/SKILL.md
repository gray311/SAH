# C2 Optimization: Step Function Initialization Replacement

## Objective
Maximize C2 > 1.026. Replace the seed's _create_step_initializer with better step function code.

## Phase 1: Replace Initialization

1. Call step_function_code_generator to get Python code for a new initializer
   Example: step_function_code_generator({"num_steps": 2, "symmetric": true})

2. Use edit_solution to REPLACE the entire _create_step_initializer method
   - Delete the old method (lines starting with def _create_step_initializer)
   - Insert the new code at that location

3. Ensure the replacement creates non-negative arrays

## Phase 2: Systematic Step Function Exploration

### 2-Step Functions (Boxcar)
- Symmetric: f(x) = h for |x| < w, 0 otherwise
- Try heights: 1.0, 1.2, 1.5, 2.0

### 3-Step Functions
- Left-middle-right pattern
- Heights: [0.8, 1.0, 0.8], [1.0, 1.5, 1.0]

### 4-Step Functions (Bimodal)
- Two peaks with valley in center
- Heights: [0.5, 1.5, 1.5, 0.5], [1.0, 2.0, 2.0, 1.0]

## Phase 3: Probe-Before-Eval

1. Generate 3-5 step function initializations (different num_steps, heights)
2. For each: call probe_solution to rank
3. Select TOP 2-3 for full evaluation

## Critical Rules

- MAX 4 full evaluations
- Always probe 3-5 variants before eval
- Replace ENTIRE method, not just parts
