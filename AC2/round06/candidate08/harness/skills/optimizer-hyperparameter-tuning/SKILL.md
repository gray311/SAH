# Hyperparameter Optimization for C2 Maximization\n\n## Objective\n\nMaximize C2 > 1.028. Current baseline: 1.02665 (seed). Target: > 1.028.\n\n## Core Strategy: Systematic Hyperparameter Sweep\n\nThe seed program is a JAX optimizer with tunable parameters. Your approach:\n\n### Phase 1: Parameter Space Exploration\n\n1. **Call param_sweeper** to generate 10-12 hyperparameter combinations\n2. Focus on key parameters:\n   - num_intervals: grid resolution (100-1000)\n   - learning_rate: step size (0.01-0.2)\n   - num_steps: optimization budget (10k-80k)\n   - warmup_steps: warmup length (1k-10k)\n   - reinit_fraction: restart rate (0.05-0.2)\n   - reinit_std: restart noise (0.01-0.05)\n\n3. **Probe each combination** (call probe_solution)\n4. **Rank by probe score**\n5. **Evaluate TOP 3** only\n\n### Phase 2: Analysis and Iteration\n\n- If improvement: analyze which parameter changed most\n- Try focusing on that parameter (narrower sweep)\n- If no improvement: try different focus (e.g., resolution vs learning rate)\n\n### Phase 3: Advanced Strategies\n\n- **Adaptive learning rate**: Try schedulers (not supported in seed, but modify warmup)\n- **Multi-stage optimization**: Coarse grid, then refine\n- **Ensemble initialization**: Combine best parameters from different runs\n\n### Critical Rules\n\n- MAX 4 full evaluations\n- Always probe 8-12 combinations before any eval\n- Track which parameter combinations worked\n- Diversify if stuck: switch focus area\n\n## Tool Usage Priority\n\n1. param_sweeper — generate hyperparameter combinations\n2. probe_solution — rank many variants cheaply\n3. edit_solution — apply top parameter set\n4. evaluate_solution — confirm only 2-3 top candidates\n5. finish — when evals exhausted or score > 1.028 achieved
