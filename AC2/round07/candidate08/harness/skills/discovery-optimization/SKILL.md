# C2 Maximization: Continuous Optimization Strategy\n\n## Understanding the Task\n\nMaximize C2 = ||f * f||_2^2 / ((int_f)^2 ||f * f||_inf)\n- Theoretical bound: 1.0 (Young's inequality)\n- Best literature value: 0.8963 (step functions)\n- **Your seed achieves 1.03336** - this is strong!\n\n## Why the Seed Works\n\nThe seed program (C2Optimizer) uses:\n- JAX for automatic differentiation\n- FFT for efficient convolution (O(n log n))\n- 400 intervals for fine discretization\n- Adaptive restart when stagnating\n- Multiple initialization patterns\n\n## Common Mistakes to Avoid\n\n1. **Discarding the seed optimizer** - it's already found 1.03336\n2. **Forcing discrete step functions** - may not beat continuous optimization\n3. **Wasting evaluations on poor initializations** - probe first!\n4. **Ignoring gradient information** - use it for refinement\n\n## Improved Strategy\n\n### Approach 1: Gradient-Based Refinement\n- Run the seed optimizer to convergence\n- Extract the best f from the final state\n- Create a new initial configuration based on this\n- Use gradient descent from a better starting point\n\n### Approach 2: Adaptive Interval Refinement\n- Start with fewer intervals (e.g., 100) to find rough good regions\n- Once converged, increase to 400+ intervals to refine\n- This uses fewer evaluations while exploring promising spaces\n\n### Approach 3: Multi-Start with Diversity\n- Modify initialization: vary the seed patterns\n- Try different total functions (don't just use the built-in ones)\n- Combine successful elements from different runs\n\n### Approach 4: Symmetry Exploitation\n- Enforce f(x) = f(-x) to reduce search space by half\n- Many optimal functions may be even/symmetric\n\n## Workflow\n\n1. **Analyze current solution**: Is it still improving or stagnant?\n2. **If stagnant after 30+ iterations**: Consider refinement strategies\n3. **Probe before evaluating**: Get 3-5 probe scores, rank, then eval top 1-2\n4. **Diversify intelligently**: Don't just perturb; use gradients or structural changes\n5. **Track progress**: Note which strategies work\n\n## Tool Usage Guide\n\n- **edit_solution**: Modify the Optimizer class - change hyperparameters, add refinement logic\n- **probe_solution**: Quick check on subsampled data. Use 5-8x per candidate family\n- **evaluate_solution**: ONLY after strong probes. Max ~20 total across entire session\n- **finish**: When you have good results or budget exhausted\n\n## Key Insight\n\nThe seed optimizer is sophisticated. Instead of replacing it, **enhance it**:\n- Better initialization strategies\n- Smarter restarts when stagnating\n- Gradient-based refinement on best solutions\n- Adaptive discretization (coarse to fine)\n\nRemember: You have 20 evaluations. Use probes for ranking, saves evaluations for the best candidates only.
