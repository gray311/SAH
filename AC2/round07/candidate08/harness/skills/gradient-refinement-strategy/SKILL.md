# Gradient Refinement Strategy for C2 Maximization\n\n## Overview\n\nEnhance the seed optimizer with gradient-based refinement and adaptive strategies. The seed already achieves 1.03336 - we're trying to beat this!\n\n## Core Strategy: From Good to Better\n\n### Step 1: Find a Solid Baseline\n- Run standard optimizer to convergence (~35000 iterations)\n- Record best f found\n- Don't rush - patience yields better solutions\n\n### Step 2: Gradient Descent Refinement\n- Extract best f from converged run\n- Create new optimizer with f as initial guess\n- Use lower learning rate (0.05-0.1 vs 0.18) for fine-tuning\n- Run for 5000-10000 iterations\n- This local search can squeeze out improvements\n\n### Step 3: Adaptive Discretization\n- Start with 100 intervals (coarse)\n- Once converged, increase to 400 intervals (refine)\n- This explores promising spaces with fewer evaluations\n- Coarse version: faster convergence to rough optimum\n- Fine version: precision in promising regions\n\n### Step 4: Multi-Start Diversity\n- When stagnating, create new initializations from best f\n- Perturb heights: +/-0.1, +/-0.15, +/-0.2\n- Perturb interval boundaries: +/-5% shifts\n- Try different total configurations (not just seed patterns)\n- Keep the one that improves fastest\n\n### Step 5: Symmetry Exploitation\n- Enforce f(x) = f(-x) when possible\n- Reduces search space by half\n- Many optimal functions are symmetric\n- Modify initialization to create even functions\n\n## Common Failure Modes to Avoid\n\n1. **Rushing the baseline**: Need good starting point before refinement\n2. **Wrong learning rate**: Too high = oscillation, too low = slow convergence\n3. **Evaluating too early**: Wait for probe confirmation\n4. **Discarding the seed**: It's already powerful - enhance, don't replace\n\n## Tool Integration\n\n- Use analyze_optimizer_state to understand current progress\n- Call probe_solution 5-6x before each full evaluation\n- Document what worked in notes/scratch\n- finish when clear improvement achieved or budget exhausted\n\n## Expected Gains\n\n- Gradient refinement: +0.001-0.005 C2\n- Adaptive discretization: +0.002-0.01 C2\n- Multi-start diversity: +0.003-0.008 C2\n- Combined: potentially +0.01-0.015 C2 from 1.03336\n\nRemember: Each evaluation is precious. Probe → rank → evaluate top candidates only.
