  description: |
    Analyze the current step pattern structure and provide detailed insights including:
    - Pattern classification (nearly_uniform, moderate_variation, high_variation)
    - Height statistics (mean, std, range, coefficient of variation)
    - Interval structure analysis (width distribution, spacing patterns)
    - Symmetry assessment (symmetric vs asymmetric, center of mass position)
    - Recommended mutation types based on structural properties
    Call this at the start of each iteration cycle.
  input_schema:
    type: object
    properties: {}
  implementation_py: |
    def run(ctx, args):
        import re
        prog = ctx.get_program()
        if "# EVOLVE-BLOCK" not in prog:
            return {"note": "no evolve block", "analysis": {}}
        
        # Extract all height values from patterns
        height_matches = re.findall(r"\.set\((\d+\.\d+)\)", prog)
        heights = [float(h) for h in height_matches if h]
        
        # Extract interval boundaries
        interval_matches = re.findall(r"at\((\d+\.\d+)*n:\s*(\d+\.\d+)*n", prog)
        intervals = []
        for match in interval_matches:
            if len(match) >= 2:
                intervals.append((float(match[0]), float(match[1])))
        
        if not heights:
            return {"note": "could not parse heights", "analysis": {}}
        
        # Compute height statistics
        avg_h = sum(heights) / len(heights)
        variance = sum((h - avg_h)**2 for h in heights) / len(heights)
        std_h = variance ** 0.5
        min_h = min(heights)
        max_h = max(heights)
        h_range = max_h - min_h
        cv = std_h / avg_h if avg_h > 0 else 0
        
        # Classify pattern
        num_levels = len(heights)
        pattern_type = "unknown"
        if h_range < 0.1:
            pattern_type = "nearly_uniform"
        elif h_range < 0.3:
            pattern_type = "moderate_variation"
        else:
            pattern_type = "high_variation"
        
        # Assess symmetry
        symmetry_score = 0.0
        if len(heights) >= 2:
            sorted_h = sorted(heights)
            center_idx = len(sorted_h) // 2
            if len(sorted_h) % 2 == 0:
                symmetry_score = 1.0 - (sorted_h[center_idx] - sorted_h[center_idx-1]) / max_h
            else:
                symmetry_score = 1.0 - abs(sorted_h[center_idx] - avg_h) / max_h
        
        # Compute interval widths
        interval_widths = []
        for i, (start, end) in enumerate(intervals):
            if i == 0:
                interval_widths.append(end - start)
            else:
                interval_widths.append(intervals[i][1] - intervals[i-1][1])
        
        avg_width = sum(interval_widths) / len(interval_widths) if interval_widths else 1.0
        
        # Determine center of mass (normalized to domain [0,1])
        if intervals:
            center_of_mass = sum((start + end) / 2.0 for start, end in intervals) / len(intervals)
        else:
            center_of_mass = 0.5
        
        # Generate mutation recommendations based on analysis
        recommendations = []
        
        if std_h > 0.1:
            recommendations.append("Consider height perturbation: adjust peaks by plus-minus 0.05-0.10")
        
        if num_levels >= 4:
            recommendations.append("Consider asymmetric variation: break symmetry in heights")
        
        if h_range > 0.5:
            recommendations.append("Consider width contraction on extreme levels")
        
        if symmetry_score > 0.8:
            recommendations.append("Consider center shift: break perfect symmetry")
        
        recommendations.append("Consider intermediate level adjustment if multi-level")
        
        return {
            "analysis": {
                "num_levels": num_levels,
                "avg_height": avg_h,
                "height_std": std_h,
                "height_range": h_range,
                "height_cv": cv,
                "pattern_type": pattern_type,
                "symmetry_score": symmetry_score,
                "num_intervals": len(intervals),
                "avg_interval_width": avg_width,
                "center_of_mass": center_of_mass
            },
            "recommendations": recommendations
        }

  ## When to Use

  After trying 2-3 variants of a mutation type without reaching the maximum improvement,
  use composite_mutator to create combinations with other successful or promising mutation types.

  ## Composite Creation Strategy

  1. Identify 2-3 mutation types that show potential (even if not fully developed)
  2. Call composite_mutator with these types and a combine strategy:
     - "sequential": Apply mutations in order (safe, conservative)
     - "parallel": Apply all changes simultaneously (more radical)
     - "weighted": Amplify certain mutations more (requires careful tuning)
  3. Use amplification_factor of 1.1-1.3 to avoid over-correction

  ## Common Effective Combinations

  - height_perturbation + width_expansion: Boost L2 norm while maintaining peak control
  - asymmetric_variation + center_shift: Break symmetry from multiple angles
  - intermediate_adjustment + height_perturbation: Refine multi-level patterns holistically
  - center_shift + width_expansion: Move and expand to find new optimal regions

  ## Execution Flow

  1. Try 2-3 variants of Mutation Type X
  2. If plateaued, try 2-3 variants of Mutation Type Y
  3. If still plateaued, call composite_mutator with [Type X, Type Y]
  4. Test the composite variant
  5. If successful, create more composites involving these types
  6. If failed, try adding a third type or different amplification

  Key Principle: Combinations can achieve what single mutations cannot - explore the
  interaction space between mutation types.'
