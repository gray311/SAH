# Pattern Enumeration Protocol for Step Functions\n\n## Phase 1: Pattern-Based Mutation (iterations 1-12)\n\n1. Call scan_step_patterns to enumerate patterns 0-11\n2. Identify active pattern or try untried patterns\n3. Generate 4 variants per active pattern:\n   - A: +5% peak height\n   - B: Widen peak (shift boundaries inward 2%)\n   - C: Narrow peak (-3%) + +0.15 height\n   - D: Asymmetric 2-peak or structural change\n4. Probe all 4, evaluate best\n5. If no improvement after 3 iterations: switch to Phase 2\n\n## Phase 2: Systematic Pattern Scan (iterations 13-20)\n\n1. Cycle through patterns 0-11\n2. For untried patterns: create +2% height variant\n3. Probe all, evaluate best\n4. If beats record: refine with gradient methods\n\n## Phase 3: Gradient Escape (iterations 21-25)\n\n1. Use JAX gradients with LARGER steps (lr=0.1)\n2. Generate 2 variants (ascent/descent)\n3. Probe both, evaluate best\n4. If gradient norm < 0.005: switch to Phase 4\n\n## Phase 4: Final Dive (iterations 26-30)\n\n1. Reinitialize 80% of parameters with std=0.05*value\n2. Create 3 variants\n3. Probe, evaluate best, submit if c2 > 0.8962799441554086\n\n## Key Rule\nSYSTEMATICALLY try patterns before perturbations - this is the critical difference from previous harnesses.
