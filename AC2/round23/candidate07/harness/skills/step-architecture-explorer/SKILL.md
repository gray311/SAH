# Step Architecture Explorer for C2 Maximization

## Core Strategy

Generate COMPLETE NEW step function configurations each iteration. Do NOT tweak existing parameters. Explore architectural diversity:

### Pattern Library

1. Single Peak: Width 30-40%, height 1.5-2.5, base 0.6-1.0
2. Dual Peaks: Two peaks at 25% and 75%, heights 1.5-2.5 each, base 0.7-1.2
3. Multi-Level (3-4 levels): Heights e.g. 0.8, 1.6, 2.4, 1.2
4. Asymmetric: Wide base 60-70% + narrow high peak 15-20%
5. Multi-Peak: 2-4 distinct peaks with varying heights

## Phase Guidelines

Phase 1 (iterations 1-12): Generate 5-8 diverse architectures, probe all, evaluate best.
Phase 2 (iterations 13-22): Generate 3 perturbations of best config, probe all, evaluate best.
Phase 3 (iterations 23-30): Generate 4-5 novel architectures, probe, evaluate best.

## Key Principle

ARCHITECTURAL DIVERSITY > PARAMETER TWEAKING. Each configuration should explore a different structural hypothesis.
