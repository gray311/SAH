      # C++ Polygon Search for Fish Packing
      
      ## Core Pattern: Iterative Optimization Loop
      ```cpp
      int best_score = -999999;
      vector<Point> best_poly = initial_poly;
      vector<Point> current_poly = initial_poly;
      
      while (elapsed_time < ACTUAL_TIME_LIMIT_SECONDS - 0.05) {
          // Generate variants
          vector<vector<Point>> variants;
          variants.push_back(mutation_flip_edge(current_poly));
          variants.push_back(mutation_adjust_coords(current_poly));
          variants.push_back(mutation_random_restart(current_poly));
          
          // Probe variants (cheap)
          for (auto& v : variants) {
              int probe_score = probe_score(v); // Fast approximation
              if (probe_score > best_score) {
                  best_poly = v;
                  best_score = probe_score;
              }
          }
          
          // Full eval on best
          int eval_score = evaluate_poly(best_poly);
          if (eval_score > best_score) {
              best_score = eval_score;
              best_poly = evaluate_best_poly(best_poly);
          }
      }
      ```
      
      ## Mutation Operators
      1. **Flip edge orientation**: Convert horizontal segment to vertical at midpoint
      2. **Coordinate perturbation**: Shift vertices by ±[5, 50, 100] in x or y
      3. **Vertex insertion**: Add a vertex at midpoint of long edge
      4. **Vertex removal**: Merge collinear vertices
      5. **Rectangle merge**: Combine two adjacent rectangles into larger shape

      - Use `set<pair<int,int>>` for O(log N) point lookup
      - Sort fish by x-coordinate for range queries
      - Precompute which grid cells each fish occupies
      - Cache query results across iterations

      - Full evaluation: reserved for final candidates only

      - Verify non-self-intersection before scoring
      - Check perimeter constraint (400000)
      - Clamp coordinates to [0, 100000]
      - Handle degenerate polygons gracefully
