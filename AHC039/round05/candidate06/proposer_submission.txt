  ## Strategy: Spatial Clustering + Iterative Construction
  
  1. **Understand the data**: Check the input for mackerel/sardine distributions. Look for clusters of mackerels.
  
  2. **Build iterative search** (most important!):
     - Start with a minimal valid polygon (e.g., a small rectangle)
     - In each iteration: try expanding the polygon in promising directions
     - Score each variant internally, keep the best
     - Terminate when time remaining < 0.2s (safety margin from 2.0s limit)
  
  3. **Expansion heuristics**:
     - If mackerels are detected at the boundary, extend in their direction
     - If sardines are detected, retract or create a "cut" around them
     - Grid-aligned means only horizontal/vertical extensions
  
  4. **Polygon construction rules**:
     - Min 4 vertices, max 1000 vertices
     - Perimeter ≤ 400,000
     - No self-intersection (orthogonal polygons need alternating directions)
  
  5. **Time awareness**: Your code must complete within ~1.8s (0.1s safety margin). Use:
     `auto start = std::chrono::steady_clock::now();`
     Loop until: `chrono::duration_cast<...>(now - start).count() > 1.7`
  
  6. **Practical starting points**:
     - Simple approach: Find bounding box of mackerel clusters → expand with checks
     - Better: Multiple small rectangles covering dense mackerel regions (takes more time to output but might score higher)
     - Avoid: Complex polygons with many vertices unless they clearly capture more mackerels
  
  ## Sample loop structure in C++:
  /*
    int mackerels = 0, sardines = 0;
    // Build initial polygon around first mackerel cluster
    std::vector<Point> poly = {...};
    
    // Iteratively improve
    int iter = 0;
    auto start = std::chrono::steady_clock::now();
    while (true) {
      // Score current polygon
      int m = count_mackerels(poly), s = count_sardines(poly);
      int best_m = m, best_s = s;
      
      // Try expansions
      for (auto& d : expansion_directions) {
        auto candidate = try_expand(poly, d);
        int cm = count_mackerels(candidate), cs = count_sardines(candidate);
        if (cm - cs + 1 > best_m - best_s + 1) {
          poly = candidate;
          best_m = cm; best_s = cs;
        }
      }
      
      auto now = std::chrono::steady_clock::now();
      auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(now - start).count();
      if (elapsed > 1700) break; // Safety margin
      iter++;
    }
