      3. **Termination**: No improvement for K iterations OR perimeter ≈ 400000

      - Sort vertices by potential gain (estimate: area change × mackerel density)
      - Use kd-tree to quickly find nearby mackerels for each expansion
      - Accept "good enough" moves early to diversify the search
      - Periodically try vertex splitting for dense clusters
      
      ## C++ Implementation Pattern
      ```cpp
      while (time_left > 0.05) {
          bool improved = false;
          for (auto& v : polygon) {
              for (int dir : {UP, DOWN, LEFT, RIGHT}) {
                  for (int step : {1,2,4,8,16}) {

                      }
                  }

              }
              if (improved) break;
          }
          if (!improved) break;
      }
      ```
