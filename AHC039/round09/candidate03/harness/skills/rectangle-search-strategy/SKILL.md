# Pair-Based Rectangle Search Strategy\n\n## Core Principle\nFind rectangles that enclose exactly 2 mackerels with 0 sardines. Score = 2 - 0 + 1 = 3.\n\n## Algorithm Steps\n\n### Step 1: Parse Input\n- Extract all mackerel coordinates: (x_m1, y_m1), (x_m2, y_m2), ...\n- Extract all sardine coordinates: (x_s1, y_s1), (x_s2, y_s2), ...\n- Store in lists for efficient querying\n\n### Step 2: Generate Rectangle Candidates\nFor each pair of mackerels (i, j) where i < j:\n- x_min = min(x_mi, x_mj)\n- x_max = max(x_mi, x_mj)\n- y_min = min(y_mi, y_mj)\n- y_max = max(y_mi, y_mj)\n- Ensure x_max >= x_min and y_max >= y_min (degenerate if equal, use width=1)\n- Check if rectangle is within bounds [0, 100000]\n\n### Step 3: Score Each Rectangle\nFor each candidate rectangle:\n- Count mackerels inside (inclusive: x_min <= x <= x_max, y_min <= y <= y_max)\n- Count sardines inside (inclusive)\n- Score = m_count - s_count + 1\n- If score > best_score, update best rectangle\n\n### Step 4: Randomized Sampling\n- With 2.0s time budget, cannot enumerate all N^2/2 pairs (12.5M)\n- Use random sampling: pick K pairs uniformly at random\n- Use bias: prefer pairs with closer coordinates (smaller rectangles)\n- Early termination: when time < 0.1s, return best found\n\n### Step 5: Fallback Strategies\nIf no good rectangle found:\n- Try single mackerel with 1x1 rectangle: score = 1 - 0 + 1 = 2\n- Try pairs with 1 sardine: score = 2 - 1 + 1 = 2\n- Always output valid 4-vertex rectangle\n\n### Step 6: Output\n- Output m=4\n- Output 4 vertices: (x_min, y_min), (x_max, y_min), (x_max, y_max), (x_min, y_max)\n- Ensure clockwise or counterclockwise order\n\n## Key Advantages\n- Simple geometry: rectangles never self-intersect\n- Fast construction: O(1) per pair\n- Many successful cases expected\n- Achievable score >= 3\n- Within all constraints\n\n## Implementation Notes\n- Use std::vector for fish storage\n- Use randomized pair selection with time-based early exit\n- Include bounds checking for all coordinates\n- Handle degenerate rectangles (width=0 or height=0) by expanding to 1\n- Always output exactly 4 vertices for axis-aligned rectangle
