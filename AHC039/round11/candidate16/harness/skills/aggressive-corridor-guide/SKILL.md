# Aggressive Corridor Expansion Guide\n\n## Core Innovation: 8-Direction Search\n\nUnlike the seed's 4-direction (cardinal only) approach, use ALL 8 directions including diagonals (NE, NW, SE, SW) to create more flexible polygon shapes.\n\n## Key Parameters\n\n- **Grid**: 200x200 with cell_size=500\n- **Top cells**: Select top 20 (include negative scores for connectors)\n- **Expansion criteria**: Continue if (M - S) > -3 (lenient vs seed's -2)\n- **Stop criteria**: (M - S) < -10 or grid boundary\n- **Max corridor length**: 150 cells per direction\n\n## Combination Probing\n\nBefore full evaluation:\n1. Generate 10-15 corridor merge configurations\n2. Use probe_corridor_combinations tool for cheap scoring\n3. Select top 3 for full evaluation\n\n## Aggressive Hill Climbing\n\n- 5 rounds (vs seed's 3)\n- Shift sizes: ±5, ±10, ±20, ±40, ±80 (vs seed's ±5..25)\n- Grid-based fast scoring\n\n## Phased Restarts (25 total)\n\n- Phase 1 (0-9): Standard corridor expansion\n- Phase 2 (10-19): Corridor + vertex swap mutations\n- Phase 3 (20-24): Aggressive expansion with large shifts\n\n## Success Factors\n\n- 8-direction expansion captures more complex shapes\n- Combination probing finds good merges without full evals\n- Larger hill climbing shifts escape local optima\n- More restarts with mutations explore diverse solutions
