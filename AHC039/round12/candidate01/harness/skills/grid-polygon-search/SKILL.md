# Grid-Based Polygon Search Strategy\n\n## Core Approach\n- Use grid (200x200, cell_size=500) for O(1) initialization and scoring\n- Build polygons from mackerel-dense regions\n- Implement edge mutation directly in C++ for efficient local search\n- Enable multi-lobed polygons for non-convex distributions\n\n## Phase 1: Grid Analysis\n- Build 200x200 grid over [0,100000]x[0,100000]\n- Count M/S per cell, compute M-S score\n- Find top 15 cells with positive score\n\n## Phase 2: Initial Polygon Construction\n- Convert top cells to bounding box polygons\n- Ensure: 4-1000 vertices, perimeter <= 400,000, coords in [0,100000]\n- Start with single polygon, then try multi-lobed structures\n\n## Phase 3: Edge Mutation (Key Innovation)\n- Implement edge-based optimization directly in C++\n- For each edge, try shifts: ±5, ±10, ±15, ±20 units\n- Use grid-based scoring for O(1) evaluation\n- Keep mutations that improve M - S\n- Repeat 3 refinement rounds\n\n## Phase 4: Multi-Lobed Strategy\n- Build separate polygons around each mackerel cluster\n- Allow multiple lobes if total perimeter < 400,000\n- Better captures non-convex distributions\n\n## Phase 5: Multiple Restarts\n- Run 15-20 restarts with different random seeds\n- Each restart: perturb top cells, build polygons, apply edge mutation\n- Output best polygon across all restarts\n\n## Success Factors\n- Grid initialization guides search but doesn't limit precision\n- Edge mutation enables efficient local search\n- Multi-lobed polygons capture complex distributions\n- Deep hill climbing fine-tunes edge positions
