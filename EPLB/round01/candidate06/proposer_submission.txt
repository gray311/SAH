      Guide the solver to optimize algorithm speed by replacing Python loops with NumPy vectorized operations and minimizing CPU overhead.
    body: |
      # Vectorization Strategy for Algorithm Speedup

      Your goal: MAXIMIZE the combined_score, which rewards BOTH correctness AND execution speed. A slow correct solution scores worse than a fast good-enough solution.

      **Step 1: Identify slow operations**
      - Python for-loops iterating over array indices (the biggest offender)
      - Generator expressions like `(i for i in range(...))` or `(... for ...)`
      - `.cpu()` calls that move data back to CPU unnecessarily
      - Repeated list operations (append, extend) inside loops
      - Inefficient use of `.expand()` or `.repeat()` without need

      **Step 2: Replace with vectorized equivalents**
      | Slow pattern | Fast alternative |
      |--------------|------------------|
      | `for x in arr: ...` | `np.where(arr > threshold, ...)` or `np.bincount(...)` |
      | `min(range(n), key=f)` | `np.argmin(f(arr))` or precompute then `arr[np.argmin(...)]` |
      | `.sort().indices` | `np.argsort()` then direct indexing |
      | List appends in loop | Pre-allocate `np.zeros(n, dtype=int)` and index directly |
      | Multiple small arrays | Fuse into single operations where possible |

      **Step 3: Keep everything on GPU**
      - Only call `.cpu()` for final return values
      - Do .sort(), .argsort() directly on GPU tensors
      - Use GPU-native operations for all intermediate steps

      **Step 4: Simplify algorithm structure**
      - Can you achieve ~90% of the load balancing with 50% the complexity?
      - Less complex code = fewer errors + faster execution = higher score

      **Concrete examples:**
      
      BEFORE (slow Python loop):
      ```python
      for group in indices[i]:
          pack = min((j for j in range(num_packs) if valid[j]), key=w.__getitem__)
      ```
      
      AFTER (vectorized):
      ```python
      valid = np.arange(num_packs)[is_valid_array]
      pack = valid[np.argmin(w[arange_len(i), valid], axis=-1)]
      ```
      
      Check each time before editing: Is this the slowest operation in the code? Start there."
