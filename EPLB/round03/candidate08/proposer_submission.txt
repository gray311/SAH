    body: |
      # MoE EPLB Strategy Guide
      
      ## Problem Understanding
      MoE EPLB takes expert load metrics and rearranges experts to minimize load variance
      while maximizing efficiency. This is an NP-hard bin-packing/assignment problem.
      
      ## Core Algorithmic Patterns
      1. **Greedy Bin-Packing**: Sort experts by weight (descending), assign to pack with minimum load
      2. **Hierarchical Grouping**: Partition at multiple levels, optimize intra- then inter-group
      3. **Balanced Packing**: Pre-allocate arrays, use vectorized torch ops for fair-share assignment
      4. **Strategic Replication**: Replicate low-weight experts to balance load distribution
      
      ## Implementation Tips
      - Use torch.sort, torch.argmin, torch.ones, torch.arange for vectorized operations
      - Pre-allocate output tensors to avoid repeated allocation in loops
      - For hierarchical: first partition into groups, then balance within each group
      - Track pack_weights and pack_items to avoid overflow
      - Tie-break by minimum weight when multiple packs have same item count
      
      ## Evaluation Strategy
      1. Call analyze_load_imbalance to understand current state
      2. Generate 3-5 complete algorithm variants (different strategies)
      3. Probe each variant (~10s per probe, 30 probes budget)
      4. Full evaluate top 2-3 variants
      5. If no improvement, try fundamentally different approach
      
      ## Common Mistakes
      - Modifying only one line (cosmetic changes don't help)
      - Repeatedly tuning the same losing variant
      - Not using probe→eval workflow for cheap ranking
      - Ignoring constraint: num_groups must be divisible by num_packs
