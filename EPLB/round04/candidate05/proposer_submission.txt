    ## Why SWABP beats the seed:
    - Seed sorts per-layer independently (misses cross-layer optimization)
    - SWABP does GLOBAL sort by weight, then assigns to bins
    - FFD (First-Fit Decreasing) is provably near-optimal for bin packing

    ```
    For each layer:
        Sort weights descending
        For each group:
            Find pack with min items, tie-break by min weight
    ```

    NEW (SWABP - working):
    ```
    Flatten all experts with (layer, group, weight) tuples
    Sort ALL by weight DESCENDING globally
    Initialize pack_weights = [0]*num_packs, pack_counts = [0]*num_packs
    For each expert in sorted order:
        Find pack with minimum (pack_count, pack_weight) tuple
        Assign expert to that pack
        Update pack tracking
    Reshape back to [num_layers, num_groups]
    ```

    ## Step 2: Vectorization tips for torch
    - Use torch.argsort() instead of Python sort()
    - Pre-allocate all output tensors with correct shapes
    - Use torch.gather/scatter for assignment if possible
    - Avoid Python list comprehensions in hot loops

    ## Step 3: Implementation template
    ```python
    def balanced_packing(weight, num_packs):
        num_layers, num_groups = weight.shape
        groups_per_pack = num_groups // num_packs
        assert num_groups % num_packs == 0
        
        if groups_per_pack == 1:
            pack_index = torch.arange(num_groups, dtype=torch.int64, device=weight.device).expand(num_layers, -1)
            rank_in_pack = torch.zeros_like(weight, dtype=torch.int64)
            return pack_index, rank_in_pack
        
        # Create flat list of all experts with weights
        all_experts = []
        for layer in range(num_layers):
            for group in range(num_groups):
                all_experts.append({
                    'layer': layer,
                    'group': group,
                    'weight': weight[layer, group].item()
                })
        
        # GLOBAL sort by weight descending
        all_experts.sort(key=lambda x: x['weight'], reverse=True)
        
        # Initialize pack tracking
        pack_weights = [0.0] * num_packs
        pack_counts = [0] * num_packs
        pack_item_list = [[] for _ in range(num_packs)]  # Track which items per pack
        
        pack_index_flat = []
        rank_in_pack_flat = []
        
        for expert in all_experts:
            # FFD: find pack with min (count, weight)
            best_pack = min(range(num_packs), 
                           key=lambda p: (pack_counts[p], pack_weights[p]))
            
            pack_index_flat.append((expert['layer'], expert['group']))
            rank_in_pack_flat.append(pack_counts[best_pack])
            
            pack_weights[best_pack] += expert['weight']
            pack_counts[best_pack] += 1
            pack_item_list[best_pack].append((expert['layer'], expert['group']))
        
        # Reshape to 2D
        pack_index = torch.full((num_layers, num_groups), -1, dtype=torch.int64, device=weight.device)
        rank_in_pack = torch.zeros((num_layers, num_groups), dtype=torch.int64, device=weight.device)
        
        items_per_pack = [len(p) for p in pack_item_list]
        cumcount = torch.cumsum(torch.tensor([0] + items_per_pack), dim=0, dtype=torch.int64)
        
        for p, items in enumerate(pack_item_list):
            start = cumcount[p].item()
            end = start + len(items)
            for idx, (layer, group) in enumerate(items):
                pack_index[layer, group] = p
                rank_in_pack[layer, group] = start + idx
        
        return pack_index, rank_in_pack
    ```
