# Erdős Minimum Overlap - Hard Step Function Strategy\n\n## Problem\nMinimize max_k ∫h(x)(1 - h(x+k)) dx for h: [0,2]→[0,1] with ∫h=1.\n\n## Why Hard Steps Matter\nThe seed optimizer uses sigmoid(latent) which creates smooth transitions. The optimum may require SHARP boundaries (true step functions). Use generate_hard_step_patterns() to create h arrays directly.\n\n## Pattern Types to Try:\n1. **Bimodal narrow peaks**: Two sharp peaks at positions 1/4 and 3/4 with Gaussian-like shapes, thresholded at 0.5\n2. **Golomb-5 spacing**: 5 peaks at optimal Golomb ruler positions [0, 1, 4, 9, 11] scaled to [0,2], each with narrow width\n3. **Triangular wave**: Linear ramps creating 3-5 level step function\n4. **Periodic threshold**: Alternating high/low regions with precise duty cycle\n\n## Optimization Workflow:\n1. Generate 4-5 hard step patterns using generate_hard_step_patterns()\n2. For each, run optimization with 5000-10000 steps, lr=0.01-0.05, penalty=10000-50000\n3. Use probe_solution to quickly rank (uses subsampled data, very fast)\n4. Evaluate top 2-3 candidates with evaluate_solution\n5. If no improvement, try different pattern parameters or seeds\n\n## Critical Edits:\n- In _get_best_initialization, add a "hard_step" mode that calls generate_hard_step_patterns() and directly uses those h arrays\n- Remove the sigmoid wrapping for initial tests, then add it back only if it helps\n- Use jnp.where for hard thresholds, not sigmoid()\n- Track c5_bound directly in probe/evaluation, not just optimization loss\n- Save the best h pattern and refine its parameters across iterations
