# Step Function Search Strategy\n\n## Core Idea\nInstead of optimizing continuous latents, directly construct THRESHOLD-BASED step functions h: [0,2]->[0,1] that satisfy integral(h)=1 exactly.\n\n## Why This Works\n- Seed optimizer wastes time training latents (120K steps)\n- Discrete step functions can be evaluated INSTANTLY\n- Simple threshold patterns often have low overlap structure\n\n## Pattern Library\n\n### Pattern A: Single step at 1.0\nh(x) = 1 if x < 1.0, else 0\n- Integral: 1*1.0 + 0*1.0 = 1 ✓\n- Simple overlap structure\n\n### Pattern B: Two steps at 0.5 and 1.5\nh(x) = 1 if x < 0.5, h(x) = 0.5 if 0.5 <= x < 1.5, h(x) = 0 if x >= 1.5\n- Integral: 0.5 + 0.5*1.0 + 0 = 1 ✓\n\n### Pattern C: Three symmetric steps\nh(x) = 1 for x in [0,a] U [b,2], h(x) = 0 for x in [a,b]\nwhere a+b = 1\n- Integral: a*1 + (1-a-b)*0 + (2-b)*1 = a + 2 - b = 1 ✓\n\n### Pattern D: N peaks at Golomb positions\nh(x) = c for x in [m_i - delta, m_i + delta], 0 otherwise\nwhere sum(2*c*delta) = 1\n\n## Implementation Steps\n\n1. EDIT _get_best_initialization to construct h directly (not latent + sigmoid)\n2. For each pattern: compute h as array of shape (N,)\n3. Verify: sum(h) * dx == 1.0 (within tolerance)\n4. Compute c5_bound immediately (no training!)\n5. Keep best candidates, call evaluate_solution\n\n## Example Edit\n\nReplace _get_best_initialization with:\n```\ndef _get_best_initialization(self, seed: int) -> jnp.ndarray:\n    N = self.hypers.num_intervals\n    h = self._make_step_pattern(seed)\n    return h\n\ndef _make_step_pattern(self, seed):\n    # Try single step\n    x = jnp.linspace(0, 2, N)\n    h = jnp.where(x < 1.0, 1.0, 0.0)\n    # Verify integral\n    dx = 2.0 / N\n    integral = jnp.sum(h) * dx\n    h = h / integral\n    return h\n```\n\n## Exploration Strategy\n- Vary step positions: try [1.0], [0.5, 1.5], [0.3, 1.7], etc.\n- Vary step heights: 0.25/1.0/0.75 combinations\n- Use 2-3 evals per pattern variation
