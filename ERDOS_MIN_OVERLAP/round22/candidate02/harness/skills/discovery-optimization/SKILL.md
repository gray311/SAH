# Erdos Multi-Candidate Search Strategy\n\n## Problem\nThe seed optimizer trains one candidate for 120000 steps with 800 intervals and high penalty. This is slow and prone to local minima.\n\n## Solution: Generate many candidates, train briefly, evaluate best\n\n## Step 1: Generate candidates\nCALL generate_candidates_tool(num_candidates=12)\n\nThis returns 12 candidates with:\n- h: the step function (pre-sigmoided, integral ~1.0)\n- c5_bound: precomputed analytical score\n- pattern_type: which pattern generated it\n\n## Step 2: Screen by analytical score\nKEEP only candidates with c5_bound < 0.37\nSKIP if integral != 1.0 (constraint violation)\n\nTypical outcome: 3-6 candidates pass the filter\n\n## Step 3: Train the top 3 candidates briefly\nFor each kept candidate:\n- Set num_intervals = 150 (faster than 800)\n- Set penalty_strength = 10 (lower than 61, allows smoother functions)\n- Set num_steps = 20000 (shorter than 120000, avoids overfitting)\n- Train for 20000 steps\n\n## Step 4: Evaluate the trained candidates\nCALL evaluate_solution on each trained candidate\n\n## Step 5: If no improvement (all scores <= 1.00001)\nGenerate NEW candidates with different patterns:\n- Try bipartite pattern (different split point)\n- Try tri-modal pattern (different peak positions)\n- Try random seeds (seed 1, 2, 3, 4, 5)\n\n## Why this works\n- 12 analytical screens vs 12 expensive trains: we pick the best starting points\n- Short training (20000 steps) vs long training: we explore more candidates per budget\n- Low intervals (150) vs high intervals (800): faster evals, less discretization artifacts\n- Low penalty (10) vs high penalty (61): smoother functions, better overlap properties\n\n## Expected outcome\nWith 12 initial candidates, we expect 3-5 to pass the c5_bound < 0.37 filter.\nTraining each for 20000 steps takes ~50% of seed time.\nWe can evaluate 3-5 candidates, and typically one will beat the seed.
