# Systematic Training Strategy\n\n## Problem\nThe seed program trains for 59000 steps per candidate with 3 restarts and 15 pattern variations. We need to explore this space efficiently.\n\n## Solution: train_and_probe_batch Tool\n\nThis tool:\n- Trains all 15 pattern initializations with the seed optimizer\n- Uses 3 restarts for diversity\n- Probes the best trained candidates analytically\n- Returns candidates with c5_bound < 0.39 worth full evaluation\n\n## Workflow\n\n1. CALL train_and_probe_batch\n\n2. Analyze returned candidates:\n   - Check their trained c5_bound values\n   - Keep candidates with c5_bound < 0.39\n   - Prioritize those with lowest c5_bound\n\n3. CALL evaluate_solution on top 2-3 candidates with lowest c5_bound\n\n4. If no improvement, call train_and_probe_batch with modified hyperparameters (e.g., different penalty_strength, num_intervals)\n\n5. Total evaluations: 2-4 max\n\n## Why This Works\n\n- Explores the full pattern space (15 patterns)\n- Leverages the seed optimizer's training capability\n- Analytical screening after training is more accurate than pre-training screening\n- Budget-efficient: 1 tool call + 2-3 evals\n\n## Expected Output\n\nTrained candidate patterns with c5_bound values. Train patterns like Golomb, Bipartite, Tri-modal, and others from the seed program. Report the best trained c5_bound for each pattern.
