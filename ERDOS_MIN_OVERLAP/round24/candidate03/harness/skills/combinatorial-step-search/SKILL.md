# Combinatorial Step Function Search for Erdos Problem\n\n## Why This Works\n\nThe seed optimizer uses gradient descent on continuous latent vectors. This is INEFFICIENT for C5 minimization because:\n1. The objective is non-smooth (max-overlap)\n2. Gradients are weak and flat\n3. Optimal solutions are discrete step functions, not smooth curves\n\nDirect combinatorial search > gradient descent.\n\n## Workflow\n\n1. CALL generate_discrete_structures()\n   - Creates 5 integral=1 step functions\n   - c5_bound computed analytically (FFT)\n   - No training needed, no eval budget spent\n\n2. EXAMINE candidates:\n   - Each has precomputed c5_bound\n   - Check which are < 0.375 (excellent)\n   - Which are 0.375-0.382 (worth eval)\n\n3. EVALUATE promising candidates:\n   - CALL evaluate_solution on those with c5_bound < 0.375\n   - Each uses 1 eval from your 30-budget\n\n4. IF NO SUCCESS: VARY structure:\n   - Change block counts: 3 -> 4 -> 5 -> 7 blocks\n   - Change block widths: narrower or wider peaks\n   - Change value distributions: more extreme (0 vs 1)\n\n5. BUDGET MANAGEMENT:\n   - 5-8 evals for discrete structures\n   - Leave 20+ evals for iteration or retry\n\n## Key Insight\n\nCombinatorial search injects a fundamentally different capability: DIRECT CONSTRUCTION OF STEP FUNCTIONS with guaranteed integral constraint. The seed optimizer cannot do this.\n
