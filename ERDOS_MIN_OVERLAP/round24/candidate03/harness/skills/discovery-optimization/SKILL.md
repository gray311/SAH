# Combinatorial Step Function Search for Erdos Problem\n\n## Core Strategy\n\nThe Erdos C5 problem is COMBINATORIAL: find a step function with low maximum overlap. Gradient descent on continuous latent vectors is INEFFICIENT because the objective is non-smooth (max-overlap) and gradients are weak. Directly construct step functions.\n\n## Step 1: Generate Discrete Structures\n\n1. CALL generate_discrete_structures()\n\ This creates 3-5 integral=1 step functions:\n   - Each is a pure step function (blocks of constant value)\n\ - Integral constraint satisfied by construction\n   - c5_bound computed analytically via FFT\n\n2. EXAMINE returned candidates:\n   - Check c5_bound for each\n   - Candidates are already evaluated (analytical score, no training)\n\n3. FILTER:\n   - KEEP if c5_bound < 0.375 (excellent, likely to beat record)\n   - CONSIDER if 0.375 <= c5_bound < 0.382 (worth full eval)\n   - DISCARD if c5_bound >= 0.382\n\n4. EVALUATE:\n   - CALL evaluate_solution on all kept candidates\n   - Each candidate gets 1 eval (you have 30 total)\n\n## Step 2: Pattern Variations (if Step 1 fails)\n\nIf no structure from generate_discrete_structures works:\n\n- Vary block count: Try 3-block, 5-block, 7-block structures\n- Vary block widths: Narrower peaks (e.g., width 0.2 instead of 0.4)\n- Vary values: More extreme (0 vs 1, or use intermediate values like 0.33, 0.66)\n- Try asymmetric distributions: More mass on one side of [0,2]\n\n## Step 3: Latent Optimization (fallback)\n\nOnly if combinatorial search fails:\n\n- Use generate_ready_candidates for 3 pre-computed latent vectors\n- Focus on latent shaping (not hyperparameter tuning)\n- Use probe_solution to screen, then evaluate\n\n## Budget Management\n\n- Discrete structures: 5-8 evals (5-8 candidates)\n- Latent optimization: 2-3 evals (2-3 candidates)\n- Total: ~10-11 evals, leaving room for iteration or retry\n\n## Expected Outcome\n\nWith combinatorial search, you should find c5_bound < 0.37 candidates quickly.\nThe seed optimizer is inefficient for this combinatorial task.\nDirect step function construction > gradient descent on latent vectors.\n
