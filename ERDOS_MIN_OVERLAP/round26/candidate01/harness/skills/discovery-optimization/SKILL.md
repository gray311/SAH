# Direct Pattern Evaluation for Erdos Problem\n\n## Core Strategy\n\nDO NOT rely on the seed optimizer's gradient descent (59k steps, 800 intervals). Instead, construct candidate step functions analytically and evaluate them directly.\n\n## Step 1: Generate Pattern Candidates\n\nCALL pattern_evaluator - this tool:\n- Constructs 3-5 discrete pattern candidates\n- Each pattern is a step function (not trainable)\n- Each has precomputed c5_bound via analytical FFT\n- Each has integral normalized to exactly 1\n\n## Step 2: Filter by Analytical Score\n\nKeep candidates with c5_bound < 0.378:\n- This threshold is liberal (probe may underestimate or overestimate)\n- Full eval is expensive (59k steps), so only test truly promising\n- Lower threshold = tighter bound\n\n## Step 3: Full Evaluation\n\nCALL evaluate_solution on each kept candidate:\n- This runs the full optimizer starting from the pattern\n- If pattern_evaluator says c5_bound ~ 0.375, full eval might reach 0.372\n- combined_score > 1.0 means success!\n\n## Pattern Classes to Generate\n\n### Golomb Ruler Pattern\n- Marks at [0.0, 0.4, 0.8, 1.2, 1.6] (equally spaced)\n- Create narrow peaks at marks, zeros elsewhere\n- This distributes mass to minimize overlap\n\n### Tri-modal Pattern\n- 3 narrow peaks at [0.4, 1.0, 1.6]\n- Each peak has small bandwidth (~0.1)\n- Mass concentrated in 3 regions, far apart\n\n### Bipartite Pattern\n- h = 1 on [0, a), h = 0 on [a, 2]\n- Normalize so integral = 1\n- Simple step function, easy to compute c5\n\n### Multi-peak Pattern\n- 4-5 narrow peaks evenly spread over [0, 2]\n- Like Golomb but with 5 peaks\n- More complex but potentially better\n\n## Step 4: If No Success\n\nTry different pattern class parameters:\n- Golomb: try marks [0, 0.35, 0.7, 1.05, 1.4, 1.75]\n- Tri-modal: try different peak locations [0.3, 1.0, 1.7]\n- Bipartite: try a = 0.4, 0.5, 0.6\n\n## Key Points\n\n1. ANALYTICAL EVALUATION is CHEAP - call pattern_evaluator multiple times\n2. PATTERN DESIGN MATTERS MORE than hyperparameters\n3. Full eval starting from good pattern should improve c5_bound\n4. If pattern_evaluator says c5_bound < 0.378, full eval is worth it
