# Erdos C5 Optimization: Hyperparameter & Seed Tuning\n\n## Core Strategy\nThe optimizer has built-in diverse initializations (15+ patterns). Use DIFFERENT SEEDS and HYPERPARAMETERS to activate them.\n\n## Step-by-Step Workflow\n\n1. VARY NUM_INTERVALS (200, 400, 800)\n   - Lower intervals = faster evaluation = more exploration\n   - Try 200 first for quick screening\n\n2. VARY PENALTY_STRENGTH (40, 80, 120)\n   - Affects integral constraint enforcement\n   - Test multiple values across different intervals\n\n3. USE DIFFERENT SEEDS (seed_start)\n   - Each seed gives different initialization from _get_best_initialization\n   - Run 3-5 different seeds per hyperparameter config\n\n4. SCREEN WITH probe_solution\n   - Run probe on multiple configs\n   - Keep those with c5_bound < 0.375\n\n5. EVALUATE TOP 2-3 candidates\n   - Full training (59000 steps)\n   - If combined_score > 1.0, finish\n\n6. If no improvement, try:\n   - Different base_learning_rate (0.001, 0.005, 0.01)\n   - Different num_steps (30000, 60000)\n\n## Key Rules\n- Always vary seed_start across runs\n- Use low num_intervals (200-400) for screening\n- NEVER evaluate without probing first\n- Track which (interval, penalty, seed) combo worked best
