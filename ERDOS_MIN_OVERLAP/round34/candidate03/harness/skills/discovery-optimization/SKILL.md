# Erdos C5 Optimization - Diverse Step-Function Search\n\n## Core Idea\nThe problem seeks a STEP FUNCTION h: [0,2]->[0,1] with integral=1 that minimizes max_k overlap.\nSmooth sigmoids are TOO SMOOTH - try PERFECT STEPS first!\n\n## Phase 1: Generate Diverse Initial Candidates\n\nGenerate h functions with DIFFERENT STRUCTURES:\n\n### Pattern A: Uniform\nh(x) = 0.5 everywhere (integral = 0.5*2 = 1 ✓)\nc5_bound will be high (lots of overlap)\n\n### Pattern B: Bipartite (Single Threshold)\nh(x) = 1 for x < t, h(x) = 0 for x >= t\nChoose t so integral = 1: t*1 + (2-t)*0 = 1 => t = 1\nSo h(x) = 1 if x < 1, else 0\n\n### Pattern C: Multi-modal (Multiple Narrow Peaks)\nh(x) = 1 at narrow intervals around x1, x2, ..., xk\nSet widths so integral = 1\nExample: three peaks of width 0.3 each at x=0.4, 1.0, 1.6\n  Total integral = 0.3*3 = 0.9 (not enough!)\n  Need widths summing to 1, e.g., three peaks of width 1/3\n\n### Pattern D: Golomb Ruler (Sparse Marks)\nh(x) = 1 at very narrow intervals around marks m1, m2, ...\nExample: marks at 0.0, 0.4, 0.8, 1.2, 1.6 with width 0.2 each\n  Total integral = 0.2*5 = 1.0 ✓\n\n### Pattern E: Sinusoidal-like (but SHARP)\nh(x) = step function approximating sin/cos shapes\nUse multiple narrow peaks at peaks of sine wave\n\n## Phase 2: Evaluate and Select\n\nFor each candidate:\n1. Compute c5_bound (lower is better)\n2. Check integral(h) ≈ 1 (adjust if needed)\n3. Select TOP 3 candidates with LOWEST c5_bound\n\n## Phase 3: Perturb and Refine\n\nFor each top candidate:\n1. SHIFT peaks slightly (±0.1)\n2. NARROW peaks (reduce width by 0.05)\n3. SPLIT peaks (one peak into two)\n4. MERGE peaks (combine two adjacent peaks)\n\nGenerate 2-3 perturbed variants of each top candidate.\n\n## Phase 4: Evaluate Perturbations\n\nEvaluate all perturbed candidates.\nKeep those with c5_bound < best_so_far.\n\n## Phase 5: Iterate\n\nRepeat Phases 1-4 with new perturbations.\n\n## Key Rules\n- START with SHARP step functions, NOT smooth sigmoids\n- ENSURE integral(h) = 1 exactly (scale appropriately)\n- TRY MANY DIFFERENT STRUCTURES (uniform, bipartite, multi-modal, Golomb)\n- PERTURB top candidates, don't start fresh\n- Evaluate only candidates with potential for improvement
