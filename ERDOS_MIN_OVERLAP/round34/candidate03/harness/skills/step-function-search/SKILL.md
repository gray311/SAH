# Step-Function Search for Erdos C5\n\n## Problem: Find h: [0,2]->[0,1] with integral=1 minimizing max_k overlap\n\n## Why Step Functions?\nThe optimal h may be a TRUE STEP FUNCTION (perfect 0/1 values), not a smooth sigmoid.\nSmooth sigmoids waste "mass" in transition regions.\n\n## Strategy\n\n### Step 1: Generate Diverse Sharp Candidates\nCreate h with DIFFERENT STRUCTURES:\n- Uniform: h=0.5 (integral=1)\n- Bipartite: h=1 for x<1, h=0 otherwise\n- Multi-modal: 3-5 narrow peaks (total width=1)\n- Golomb-ruler: sparse marks at [0,0.4,0.8,1.2,1.6]\n- Sinusoidal peaks: at sin(2πx) maxima\n\n### Step 2: Evaluate All Candidates\nCompute c5_bound for each.\nSelect TOP 3 with LOWEST c5_bound.\n\n### Step 3: Perturb Top Candidates\nFor each top candidate, create variants:\n- SHIFT: move all peaks by ±0.1\n- NARROW: reduce peak widths by 10%\n- SPLIT: divide one peak into two\n- MERGE: combine two adjacent peaks\n- REORDER: rearrange peak positions\n\n### Step 4: Evaluate Perturbations\nKeep any with c5_bound < best_so_far.\n\n### Step 5: Iterate\nRepeat with new perturbations.\n\n## Key Rules\n- Use SHARP steps (0 or 1), NOT smooth sigmoids\n- Always normalize integral(h)=1\n- Explore MANY structures before refining\n- Perturb, don't restart from scratch
