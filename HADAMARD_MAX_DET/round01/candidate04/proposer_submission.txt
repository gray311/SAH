      def run(ctx, args):
          import random
          matrix = args.get('matrix')
          if not matrix or len(matrix) != 29:
              return {"note": "Matrix must be 29x29", "suggestions": []}
          n = len(matrix)
          suggestions = []
          det_patterns = set()
          for i in range(n):
              row = matrix[i]
              if row == [1]*n: det_patterns.add("all_ones")
              if row == [-1]*n: det_patterns.add("all_neg")
              if row == [1]*n and matrix[0] == row: det_patterns.add("dup_row")
          if "dup_row" in det_patterns:
              suggestions.append({"type": "remove_duplicate", "priority": 1.0, "desc": "Remove duplicate rows to restore rank"})
          suggestions.append({"type": "flip_2x2", "priority": 0.8, "desc": "Flip 2x2 blocks: for positions (i,j),(i+1,j+1) flip signs", "note": "Try all overlapping 2x2 blocks"})

    description: |
      Playbook for maximizing Hadamard matrix determinants. Focus on multi-strategy exploration: try diverse initializations, use structured mutations, run parallel short searches, and avoid local optima by resetting with new seeds.
    body: |
      # Hadamard Determinant Maximization Playbook
      
      ## Core Principle: Diversity Over Refinement
      
      The seed uses quadratic residues + hill climbing, which finds local optima quickly. For n=29 (no perfect Hadamard), we need **exploration diversity**.
      
      ## Strategy 1: Multiple Initializations
      
      Per evaluation, run 3-5 independent searches with:
      - **Random init** + annealing (temp0=0.8, 500 iters, seed=random)
      - **Paley-like** (if n≡3 mod 4: use quadratic residues mod n)
      - **Cyclic shift** of random rows
      - **Tensor product** starting point (smaller Hadamard tensor)
      - **Block construction** (divide into submatrices, optimize separately)
      
      Return the BEST result across all searches.
      
      ## Strategy 2: Post-Construction Improvement
      
      After finding a candidate matrix, apply targeted mutations:
      
      **2x2 Block Flips**:
      For each top-left corner (i,j), flip the 2x2 block:
      ```
      A[i][j]  A[i][j+1]  ->  -A[i][j]  -A[i][j+1]
      A[i+1][j] A[i+1][j+1]  -A[i+1][j] -A[i+1][j+1]
      ```
      Accept only if |det| increases.
      
      **Row/Column Swaps**: Try swapping adjacent rows/cols (O(n) per swap). Accept if improves.
      
      **Local Annealing**: Flip one entry at a time, accept with probability exp((new-old)/T). Run 500-1000 iters.
      
      ## Time Budget Discipline (350s per eval)
      
      ❌ DON'T: One 2000-iter search (may timeout)
      ✅ DO: Three 600-iter searches in parallel with different seeds
      ✅ DO: Two 800-iter + one 400-iter searches
      
      Use `import time; elapsed = time.time() - start; max_iter = int(250 / (elapsed * n**2))` to compute safe iteration counts.
      
      ## When to Reset
      
      If best score hasn't improved in 3 consecutive evaluations, restart with a **completely different** strategy (new init method, new search type).
      
      ## Edge Cases
      
      - n=29: No perfect Hadamard exists. Max achievable |det| is likely 2^27 ≈ 1.34e8
      - If |det| < 10^7, the matrix is likely nearly singular — try breaking duplicate rows
      - If all entries on diagonals are same, perturb them randomly
      
      ## Key Heuristics
      
      1. **Early diversity**: Try multiple init methods before refining any one
      2. **Short parallel searches**: Better than one long search
      3. **Structure-aware mutations**: 2x2 flips > random flips
      4. **Timeout-safe loops**: Compute max iterations dynamically
      5. **Persistent best**: Keep and reuse the highest-scoring matrix across evaluations
