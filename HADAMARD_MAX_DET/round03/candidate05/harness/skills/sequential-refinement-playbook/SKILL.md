# Sequential Refinement for Hadamard Optimization (n=29)

## Why Sequential?

Each of your 20 evaluations is precious. Parallel exploration wastes time.\n\n**Sequential refinement maximizes each evaluation:**\n1. **Convergence**: Let ONE method run to near-convergence (25k-30k iters)\n2. **Inheritance**: Use the best result as the seed for the next evaluation\n3. **Accumulation**: Improvements compound across evaluations\n4. **Focus**: All 350 seconds go into ONE promising direction\n\n## The Protocol\n\n### Evaluation 1-3: Establish Baseline\n- Method: Paley construction\n- Parameters: T=5.0, cool_rate=0.998\n- Iterations: 25,000 per seed\n- Seeds: 3 per evaluation\n- Action: Probe 2 variants, evaluate best\n\n### Evaluation 4-6: Refine Parameters\n- Keep: Paley construction, same seed from Eval 3\n- Change: Try T=2.5, cool_rate=0.995\n- Action: Probe cooling schedule variants, evaluate\n\n### Evaluation 7-9: Final Tuning\n- Keep: Paley construction, seed from Eval 6\n- Change: Try T=1.0, cool_rate=0.992\n- Action: Probe fine-tuning variants, evaluate\n\n### Evaluation 10+: Plateau Response\n- If 3+ evaluations with <1% improvement:\n  - Switch to: Random start construction\n  - Use previous best as initial perturbation\n  - Try 20,000-25,000 iterations\n  - Probe new method variants\n\n## Critical Checklist\n\n✅ **ALWAYS**: Seed from previous best result\n✅ **ALWAYS**: ONE method per evaluation\n✅ **ALWAYS**: 25,000+ iterations for Paley, 20,000+ for random\n✅ **ALWAYS**: numpy.linalg.det during search (NEVER Bareiss during search)\n✅ **ALWAYS**: Probe 2-3 variants before evaluate_solution\n✅ **ONLY IF PLATEAU**: After 3+ evaluations with <1% improvement, switch methods\n\n## Expected Progression\n\n- Eval 1-3: 0.46 → 0.50 → 0.53\n- Eval 4-6: 0.55 → 0.58 → 0.61\n- Eval 7-9: 0.63 → 0.66 → 0.68\n- Eval 10+: Switch if plateau, aim for 0.70+\n\n## Common Mistakes to Avoid\n\n❌ Fresh start each evaluation (wastes convergence)\n❌ Multiple methods in one evaluation (dilutes effort)\n❌ Using Bareiss during search (timeout)\n❌ <20,000 iterations (insufficient exploration)\n❌ No probing before evaluate (missed better variants)\n❌ Switching methods too early (premature abandonment)"
